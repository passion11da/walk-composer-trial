# あなたの散歩が音楽に（体験版）

歩きながら撮った写真と、撮った時刻から、その散歩の曲を作る Web アプリの体験版です。

- アプリ：https://passion11da.github.io/walk-composer-trial/
- 前の版：体験版 1.0.5 … https://passion11da.github.io/walk-composer-trial/v/1.0.5/ （前の版は `v/版の番号/` に残す）
- 写真・記録は、使う人のスマホの中にだけ保存されます（アプリが外に送ることはありません）。
- 特許出願中。このリポジトリは公開用の体験版のファイルだけを置いています。
- サンプルの散歩の写真は、ウィキメディア・コモンズの自由に使える写真です（出典はアプリの中に表示）。
